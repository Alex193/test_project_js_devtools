# DevTools Redirect

`main.html` содержит ссылку на `2.html`, подключённый на второй странице `security.js` перенаправляет обратно при
обнаружении геометрических признаков закреплённой панели DevTools.


## Запуск

Нужен Node.js 22 или новее. Внешних зависимостей, установки пакетов и сборки нет.

```bash
npm start
```

Откройте **http://127.0.0.1:8080/main.html**.

или на Python

```bash
python -m http.server 8080 --bind 127.0.0.1
```

## Проверка работы

1. Откройте настольный браузер, установите масштаб страницы 100%, закройте боковые
   панели и отключите эмуляцию мобильного устройства.
2. Откройте `main.html` при закрытых DevTools.
3. Нажмите «Перейти на 2.html»: должна открыться вторая страница.
4. Вернитесь на `main.html`.
5. Откройте DevTools и **закрепите справа или снизу в том же окне**.
   Сделайте панель достаточно широкой/высокой, например 350 CSS-пикселей.
6. Повторно нажмите ссылку на `2.html`.
7. Ожидается возврат на `main.html` без нажатия Resume и без закрытия DevTools.

## Как устроено решение

1. В `2.html` перед содержимым `body` подключён обычный блокирующий
   `<script src="./security.js"></script>`.
2. Скрипт немедленно сравнивает внутренние и внешние размеры окна. Не нужно
   предварительно открывать страницу с закрытыми DevTools для калибровки.
3. При положительном сигнале скрывает содержимое и вызывает
   `location.replace(new URL('./main.html', location.href))`.
4. При отсутствии сигнала разрешает отображение и проверяет размеры по
   `resize`, `focus`, `pageshow`, возвращению видимости и таймеру 250 мс.

`replace` заменяет текущую запись истории, поэтому заблокированная загрузка
`2.html` не создаёт отдельную запись для кнопки «Назад». Проверка `pageshow`
нужна в том числе при восстановлении из кеша истории — bfcache.

Содержимое скрыто до успешного выполнения начальной проверки. Если JS отключён
или `security.js` не загрузился, остаётся диагностическое сообщение. Это
поведение интерфейса, а не защита данных: HTML уже передан браузеру.


## Проверки

```bash
npm test
npm run check
```

Встроенный `node:test` проверяет немедленное перенаправление при заранее
заданных размерах, последующее открытие панели, события жизненного цикла,
порог, отсутствие повторных перенаправлений, вложенный URL и HTTP-раздачу.
Отдельные проверки фиксируют известные ограничения метода.

Для статического хостинга достаточно `main.html`, `2.html`, `security.js` и
`styles.css`. Переходите непосредственно на `/main.html`: отдельного `index.html`
в проекте нет. Относительные ссылки работают при размещении в подкаталоге.
